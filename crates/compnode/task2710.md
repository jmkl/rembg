  Decisions
- Raw Filter implemented as FilterKind::RawFilter registered in the existing generic filter/node catalog.
- Image pipeline order: noise reduction → white balance → dehaze → texture → clarity → sharpen; alpha preserved.
- Diagnosis based on release-mode benchmarks: filter previews re-downscale full-res input on every evaluation (~47ms for 12MP), RawFilter does four image::imageops::fast_blur calls (~75ms preview, 16.7s full 12MP), and scalar single-threaded per-pixel filters are inherently slow; full-res pipeline also adds PNG encode (89ms), decode (105ms), SHA-256 hashing, and UI-thread thumbnail (21ms).
- Chosen fixes in progress: (1) cache evaluation-resolution image in Preview to avoid repeated full-res downscales; (2) replace RawFilter RGBA blurs with custom single-channel luma blurs plus one RGB blur for noise reduction.
- Planned but not yet applied: custom box-blur implementation in rawfilter.rs, possibly rayon parallelization, and moving full-res thumbnail off UI thread.
